Non-market housing projects in Vancouver. Non-market housing includes social, supportive, and co-op housing intended for low to moderate-income individuals and families.

- Index Number: Unique project identifier
- Name: Project name
- Address: Street address
- Project Status: Proposed, Approved, Under Construction, or Completed
- Occupancy Year: Year the project became occupied (integer, may be null for unbuilt projects)
- Operator: Organization operating the project (e.g., BC Housing, co-op associations)
- Clientele - Families, Clientele - Seniors, Clientele - Other: Unit counts by clientele type
- Design - Accessible/Adaptable/Standard 1BR, 2BR, 3BR, 4BR, Studio, Room: Unit counts by design type and bedroom size
- Local Area: Vancouver neighbourhood (e.g., Kitsilano, Downtown, Mount Pleasant)
- Adaptable, Accessible, Standard: Total unit counts by design category
- URL: Link to project details on Vancouver's website
